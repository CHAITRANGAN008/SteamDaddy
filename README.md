# SteamDaddy

SteamDaddy is a PowerShell-based utility for Steam-related management and troubleshooting.

## Features

- Steam-related DLC management
- Steam connection troubleshooting
- Purchase error troubleshooting
- Steam manifest management
- Online fixes
- Millennium plugin support

## Technology

- PowerShell
- Steam ecosystem
- Millennium plugin integration
